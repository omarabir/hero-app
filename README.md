# HERO.IO (hero-app)

## App Name

HERO.IO

* live link : [https://hero-app1.netlify.app/](https://hero-app1.netlify.app/)

## Description

HERO.IO is a small marketplace/demo app that showcases a curated list of applications. Users can browse trending apps, view trending and all available apps, see detailed statistics (downloads, ratings, reviews), and simulate installation. The project demonstrates modern frontend patterns such as client-side routing, loaders, component composition, and lightweight charting.

## Technologies

* React (JSX)
* Vite (dev server / bundler)
* React Router DOM (routing & loaders)
* Tailwind CSS (utility-first styling)
* Recharts (charts)
* React Toastify (notifications)
* Lucide Icons (icons)

## Quick start

1. Install dependencies:

```bash
npm install
```

2. Run the dev server:

```bash
npm run dev
```

3. Open the app in the browser at the URL Vite shows (usually [http://localhost:5173](http://localhost:5173)).

## Run Locally (Full Guide)

To run HERO.IO on your local machine:

* Clone the repository

```bash
git clone https://github.com/omarabir/hero-app
```

* Go to the project directory

```bash
cd hero-app
```

* Install required packages

```bash
npm install
```

* Start the development server

```bash
npm run dev
```

* Open the project in the browser

```
http://localhost:5173
```
